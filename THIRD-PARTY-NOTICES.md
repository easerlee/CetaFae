# Third-party integration notices

## Filee 2.4.0

Filee is developed by Myeonggu Kim (KnifeLemon) and the Filee contributors. CetaFae invokes the Filee Windows portable command-line tool through its conversion adapter. The main installer contains the adapter and these notices. The separate conversion bundle contains the unchanged upstream Windows x64 portable archive, Filee’s original MIT license, the upstream dependency notices and a link to the source release. Its included components retain their respective licenses.
