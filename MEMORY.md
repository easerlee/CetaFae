## Durable Engineering Lessons

- Read only the selected target. Capture is target-only PrintWindow in memory, without screen-region fallback. Non-black output alone does not prove freshness.
- Revalidate the entire candidate context after a model answer, including explanation-only answers. A surviving navigation control cannot prove the page is unchanged.
- A WinEvent is a reason to compare context, not proof of navigation. Hosted content can originate in another process; filter by target HWND ancestry instead of frame PID.
- Transient UIA ScrollBar descendants caused false cancellation. Exclude them by ancestry, preserving detection of genuine content changes.
- Drag anchoring must use the ball-local grab point captured in the mouse-down event before cancellation/layout work; a later pointer sample can already be displaced.
- Tests, generated model data and human desktop acceptance are different evidence. Direct results and limitations are consolidated in `验证记录.md`; do not copy historical measurements into multiple documents.
- Generated files belong under `.artifacts/`; actual source remains under `src/`. README is the entry point; Tech-Spec describes current contracts, not another requirements document.
- WPF editable controls need normal globalization: invariant mode crashed when Chinese input focus loaded locale 2052. Keep it disabled and run non-desktop checks with the application's generated runtime configuration as well as the check runner's own configuration. Initialize the console runner's dispatcher before reading WPF input language; this opens no window. The locale regression and subsequent human typing/submission passed for the exercised Edge Downloads path; detailed acceptance remains in the verification record.
- SetForegroundWindow acceptance is not synchronous foreground completion across processes. Real logs showed accepted=true, immediate HWND=0, then the target 3–4ms later. Confirm with a request-scoped cancellable wait before content observation, preserving unrelated-window cancellation. Generated transition tests do not establish native activation acceptance.
- One processing stage shares its 15-second budget across activation, observation, model and final validation. Keep that deadline separate from the retained session token, so a successful answer does not auto-clear when the former processing deadline expires. Clarification submission uses the same asynchronous foreground confirmation as a drop.
- Native UIA/PrintWindow reads now run in serialized headless MTA collectors. Cancel/timeout kills and reaps only the owned collector before admitting another; it does not stop the target application's provider. Parent/child exchange is bounded and memory-only, child diagnostics are suppressed, and the model key is excluded from the collector environment. A per-child watchdog bounds orphan lifetime. Headless fixtures are engineering evidence; real target identities, focus, timing and resource effects still need desktop verification.
- Plugins are immutable startup data snapshots. A selected definition is passed to the trusted collector, which validates the real target and returns its bound plugin ID; subsequent context reads use that same catalog snapshot. Do not reload package files during a request. Empty/disabled catalogs have no fallback; ambiguous target matches fail visibly. Current catalog changes require restart; future live management must cancel affected sessions. Ordinary child processes and .NET assembly loaders are not security sandboxes for third-party code.
