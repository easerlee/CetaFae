# 鲸汐 CetaFae

**电脑上遇到不明白的事，把小鲸鱼拖过去。**

鲸汐是陪在桌面上的电脑助手。看不懂软件界面、遇到报错，或想处理文件时，直接告诉它；需要看现场，就把小鲸鱼拖到对应窗口。它会解释问题、带你找到操作位置，并协助完成已支持的处理。

## 功能亮点

### 看不懂，帮你讲清楚

把鲸鱼拖到窗口，它会简要说明这是什么软件、正在显示什么。遇到英文、复杂选项或报错，可以继续问“这是什么意思”“我该怎么办”，也可以框选一小块画面解释或翻译。

### 不知道怎么办，带你解决

说出目标，例如“下载前询问的开关在哪里”。鲸汐会给出步骤，并在有可靠位置依据时标出对应按钮或文字。操作后可以继续提问；临时切到其他窗口再回来，仍能接着处理原来的问题。报错帮助会先概括问题，再给一个可尝试的办法，并根据你的反馈继续排查。

### 重复的小事，帮你处理

- **截图与取字**：截取选中的窗口，裁剪、标注、遮盖、复制、保存或贴在桌面参考；提取文字后，可编辑、翻译、概括或改写。
- **图片转换与压缩**：告诉鲸汐图片要用来做什么，它会推荐适合的格式。支持静态图片转 JPG、PNG、WebP 或 PDF，以及单张 JPG、PNG、BMP 压缩为指定大小的 JPG 副本。转换在本机完成，保留原文件；首次使用可能需要下载可选组件。
- **文件帮助**：查看磁盘容量、统计你选中的文件夹、读取所选 UTF-8 文本；也支持预览后保存文字、复制、移动、删除文件，以及替换纯文字。改动前确认范围，改动后核对结果；可从“操作记录”查看支持恢复的项目。
- **内存帮助**：查看哪些软件占用较多、释放所选软件的暂用内存并观察效果。可选开启持续高占用提醒，默认关闭，不会自动清理；释放内存可能很快回升，不保证电脑因此变快。

点击桌面上的鲸鱼，也能直接聊电脑和软件问题。待命对话条的“＋”支持选图或粘贴图片；拖到窗口后的对话条保持简洁，工具可从鲸鱼右键或托盘菜单打开。

## 开始使用

1. **安装**：下载上方的 Windows x64 安装包，阅读并确认协议。升级时会先退出被替换的鲸汐，安装后自动启动。程序安装到当前用户目录，无需管理员权限，也无需预装 .NET。
2. **连接模型服务**：右键鲸鱼 → **鲸汐设置 → 连接**，设置服务地址和模型。看图功能需要支持图片输入的服务，可用“检测图片识别”发送一张生成图片检查连接。检测可能消耗一次模型额度。
3. **开始求助**：点击鲸鱼输入问题，或把它拖到需要帮助的窗口。试着说：“这个提示是什么意思？”“我想把下载文件存到另一个地方。”“图片太大，发不出去怎么办？”

**还没有模型服务？** 当前版本尚未提供开箱即用的内置服务。可以先请熟悉配置的人协助；需要密钥的服务，目前通过环境变量配置，详见下方维护说明。截图、取字和已安装组件的图片转换等本机工具不依赖 AI 回答。

安装包目前未做代码签名，Windows 可能提示未知发布者。请核对下载来源；发布附件提供 `SHA256SUMS.txt` 校验文件。

### 几个常用操作

- **继续聊**：直接在原输入框接着问，不必重复描述全部背景。
- **收起桌面对话**：点击其他位置即可隐藏，再点鲸鱼恢复。完成的文字对话会在本机加密保存，重启后仍在；点清扫图标才删除。
- **结束窗口求助**：点击对话条内的“×”，或把鲸鱼拖走。窗口指导与桌面对话分别管理。
- **设置与工具**：右键鲸鱼，或点击系统托盘中的鲸鱼图标。
- **全屏时**：其他软件全屏会自动隐藏待命鲸鱼，退出全屏后恢复。

## 安全保障

- **只看你选的窗口**：不会先截取整个桌面再裁剪，也不自动读取其他窗口或后台标签。首次解读可能发送所选窗口的完整画面；你主动框选后，不会悄悄扩大到整窗。
- **发送前知道去向**：安装协议说明内容范围和模型服务。可以在设置中查看、撤回同意；更换接收方、模型或图片范围后，需要重新确认。已发送的内容无法从上游撤回。
- **尽力发现敏感信息**：发现密码字段或明显密钥时会停止。但自动检查可能遗漏，请先隐藏不愿发送的内容。
- **区分本机处理与 AI 请求**：截图、文字提取、图片转换在本机进行。向 AI 提问、发图或点击翻译等处理时，相关内容才会发往你配置的服务。截图和原始控件内容不写入对话历史；桌面文字对话及文件恢复材料在本机按当前 Windows 用户加密保存。元数据日志默认保留 7 天，当前尚未核实上游服务的留存政策，使用前请另行了解。
- **改动有范围**：鲸汐目前不会随意代点其他软件、输入内容或修改系统设置。已开放的文件改动有对象选择、预览、结果核对及适用的恢复流程；并非所有操作都能撤销。
- **插件需可信**：只启用来源可信的插件。当前执行器提供接口和资源限制，不等于完整的操作系统安全沙箱。

## 当前限制

鲸汐仍在打磨。模型可能误解内容，遇到重要文件、付费、删除或系统设置时，请核对建议。受保护窗口、权限限制、动态界面以及不同缩放、多显示器环境可能影响识别与位置提示。

部分日常工具使用独立工具窗口；图片转换目前以单张静态图片为主，尚无通用格式转换或批处理能力。没有通用自动修复、任意脚本执行或完整文档编辑。广泛软件兼容性、多步任务、响应速度、内存占用和第三方插件安全仍有验收工作；本次发布不表示这些项目已经全部通过。[实际验证记录](验证记录.md)与[测试计划](Test-Plan.md)分别列出已做和待做的验证。

## 技术实现

鲸汐使用 **C# / WPF / .NET 8** 构建 Windows 交互底座，负责窗口选择、限定采集、授权、模型连接、结果核对与存储；具体功能由 **TypeScript 插件**提供。第一方功能和第三方扩展使用同一套接口。

窗口理解以所选窗口截图为主，控件信息和本机文字识别辅助定位。图片通过绑定窗口的捕获通道取得，不向目标软件注入代码。AI 只能从已有位置依据中选择标记，无法可靠定位时不会编造坐标。部分窗口捕获通道可能显示 Windows 自带的捕获边框。

图片转换使用本机 [Filee](https://github.com/KnifeLemon/Filee) 组件，缺少时按需下载固定版本，也支持离线导入。第三方代码与组件的来源、许可和用途见[第三方声明](THIRD-PARTY-NOTICES.md)。

<summary>维护与源码构建</summary>

需要 Windows、.NET 8 SDK 和 Node.js 开发环境。Node.js 仅用于构建插件，最终用户无需安装。

```powershell
npm ci
dotnet build src/CetaFae.Checks/CetaFae.Checks.csproj -c Debug
dotnet run --project src/CetaFae.Checks -c Debug --no-build
dotnet run --project src/CetaFae.Probe -c Release -- --guide
```

最后一条命令会打开可见界面。默认开发连接为 `http://127.0.0.1:8787/v1`，模型为 `deepseek-v4.1-flash`；这不是随包提供的服务。可在设置中保存连接，远程服务须使用 HTTPS，本机回环可使用 HTTP。可选鉴权从进程环境变量 `CETAFAE_API_KEY` 读取，设置窗口不保存密钥。不要将密钥提交到仓库。

构建自包含安装包需 Inno Setup 6.7.4 及简体中文语言文件：

```powershell
./installer/Build-Installer.ps1 -Compiler 'C:/Program Files (x86)/Inno Setup 6/ISCC.exe' -ChineseMessagesFile 'C:/Program Files (x86)/Inno Setup 6/Languages/ChineseSimplified.isl'
```

产物位于 `.artifacts/installer/`。主要目录为 `src/CetaFae.Probe`（宿主）、`src/CetaFae.Plugins`（插件运行时）、`plugins`（功能包）、`plugin-sdk`（TS 契约）和 `src/CetaFae.Checks`（检查）。

[需求文档](需求文档.md)定义范围，[技术设计](Tech-Spec.md)说明实现。构建、截图及诊断产物放在忽略目录 `.artifacts/`。

## 开发计划

- 提升通用窗口理解、报错排查与多步指导的可靠性，让建议更贴近实际问题。
- 完成常用软件、高缩放和多显示器兼容性验证，改善等待、失败恢复及资源占用。
- 简化模型服务的接入与分发，让不懂配置的人也能开始使用。
- 完善截图、文字处理、图片转换和内存帮助的完整任务流程。
- 持续扩展有明确范围、可核对结果的本机处理能力，并完善恢复流程。
- 稳定插件接口、补齐安全审计；后续按统一规则支持主题和动效扩展。

## 第三方插件接口

开发者可用 TypeScript 编写功能，或用 JSON 编写适配规则。通过 **鲸汐设置 → 功能 → 导入插件文件** 导入；查看声明范围、勾选并保存后才启用。接口仍在开发，不支持任意 Node/npm 模块或绕过底座直接操作电脑。

作者说明见 [Plugin API](Plugin-API.md)，可参考[适配规则示例](examples/plugins/example.editor.json)和 [TS 功能示例](examples/plugins/example.chat/plugin.ts)。当前没有插件商店或通用静默更新。
