# 鲸汐 CetaFae

把小鲸鱼拖到一个窗口，了解它是什么、当前显示什么，并找到下一步该操作的位置。

简体中文 | [English](README.en.md)

> 当前工程版本为 **0.3.1-preview.6**。鲸汐提供解释和指路，目标软件由用户操作。正式发布验收仍在进行。

## 功能亮点

- **轻量管理**：鲸鱼左键不弹出管理窗口；托盘和鲸鱼右键共用菜单。安装时一次“同意协议并安装”，装好后直接拖鱼使用，无首次启动确认或日常云端开关；设置保留说明与撤回，启动本身不采集或发送。
- **按需出现**：就绪等临时提示可用右上角×或点击外部关闭；其他软件在前台全屏时自动隐藏待命鲸鱼，退出全屏后恢复。普通最大化和主动求助不受影响；全屏判断只用本机窗口几何信息，不分析画面。
- **拖入即选窗**：小鲸鱼与对话条在目标窗口顶部居中，对话条宽度随窗口调整，按需呈现说明和指路标记；结束会话后恢复鲸鱼入口。
- **贴近目标的反馈**：识别期间用海浪往返扫描提示等待，取得结果后才显示说明卡片。普通窗口的卡片衔接对话条，贴顶布局优先放在对话条右侧；可靠定位时避让目标控件，空间不足时自动收起并可重新展开。卡片基础宽度随对话条调整，长文先增高、再扩宽，达到屏幕限制后本地翻页，不显示正文滚动条。只按需显示“继续提问”“选择识别区域”或“展开详情”，对话条内×结束求助；管理操作放在托盘与鲸鱼右键菜单。
- **认识当前窗口**：以所选窗口截图为主，软件适配和控件信息为可选增强；先说明软件用途和有依据的名称，再简述内容或状态，通常一至两句话。认不出名称时仍可解释可读内容，不猜测未知信息。初次解释依据本次画面，后续提出目标时重新读取。读取与识别服务失败分别反馈，不堆放专业术语。不保证所有受保护或不可读取窗口都能识别。
- **解释与指路**：说明当前状态，目标不明确时询问一次。可靠定位后才标出控件，无法确认时明确说明，不猜点击位置。
- **局部画面分析**：优先使用可靠任务范围，无法确认范围时引导手动框选需要分析的区域，无需逐个软件适配才能使用通用图片理解。
- **文字位置提示（开发验证）**：通用插件可借助本机文字识别，为已选画面中的文字提供位置候选。模型只能选择已有位置，不能编造坐标；提示会明确区分文字区域与按钮范围。重复文字、缺少识读支持或证据不足时不猜位置，真实软件覆盖仍待验收。
- **界面中英解释与翻译**：在回答中说明翻译目标，按需框选文字区域；展示识读原文和译文，并检查可识别的错误码、日期、数值及单位。看不清时说明限制，不替换软件界面。
- **报错排查指路**：用日常语言简述哪个软件遇到了什么问题，再给一个安全的核对动作，或问一个必要问题；默认不复述整段报错、错误码或未经证实的原因。可在同一窗口继续提问；不会自动查日志、扫描其他进程或执行修复。
- **同窗口继续提问**：结果就绪后可直接输入下一问，也可点“继续提问”后自行操作，再提交问题。每次提交都重新核对同一窗口，最多支持八步。真实多步操作仍待集中验收。
- **插件化能力**：通用视觉、软件身份和软件适配采用同一声明式契约，第一方功能也通过插件提供。
- **按需设置**：从托盘或鲸鱼右键打开“鲸汐设置”，管理连接、隐私和随包功能，主动检测模型服务或导出不含会话内容的安全诊断。修改接收方、模型或图片范围后重新授权。

已有人工验证的代表流程包括 Edge 下载开关定位、Windows 更新暂停状态解释、WinRAR 解压目标路径指路，以及记事本生成文字的区域解释。这不代表相关软件全部功能已覆盖，也不代表最新源码的所有路径已完成回归。

## 安全保障

- **一次确认与随时撤回**：开始前说明发送范围、接收地址、模型与留存情况。可从设置隐私页撤回同意，停止新采集和请求并结束当前会话；再次使用须重新确认，已发送内容无法从上游撤回。
- **只处理所选窗口**：不先截图整个桌面再裁剪，不自动读取其他窗口或后台标签页。
- **限制外发范围**：初次了解窗口时可能发送所选整窗画面；明确目标后使用可靠局部范围或用户选区，范围不明则等待选择，不自动扩大到整窗。系统窗口捕获与 PrintWindow 均限于所选窗口；局部请求在本机内存裁剪后外发。
- **尽力检查敏感内容**：发现密码字段或明显凭据时停止；控件信息不完整时仍可用所选窗口截图解释。自动检查可能遗漏，请先隐藏不愿发送的信息；不保证发现全部秘密或自动脱敏。
- **不保存会话原文**：客户端不持久保存图片、控件原文和问答；固定元数据日志保留7天，清理失败可能延迟。代理及上游模型的留存政策尚未核实。
- **用户掌握操作权**：当前不自动点击、输入目标软件、修改设置、执行解压或写入文档。切窗、关闭目标、撤权和结束会话会清理失效结果。

## 快速开始

从 [GitHub Releases](https://github.com/easerlee/CetaFae/releases) 下载 Windows x64 预览包，解压后运行 `CetaFae.Probe.exe`。旧版解压包需要 Windows 和 [.NET 8 桌面运行时](https://dotnet.microsoft.com/download/dotnet/8.0)。发布附件可能落后于主分支，以对应版本说明为准。

默认服务为 `http://127.0.0.1:8787/v1`，模型为 `deepseek-v4.1-flash`。请先准备兼容模型服务；鲸汐不附带模型或代理。图片理解需要服务支持多模态输入。

一次识别的处理预算为60秒，期间可以结束求助。切换到其他窗口会隐藏会话效果并保留绑定；已发送的请求继续处理，返回原窗口并通过核对后才展示结果。后台不读取新内容。较长等待不代表目标软件故障，识别服务的速度与稳定性仍受所配置通道影响。

主分支可从“鲸汐设置 → 连接 → 高级连接设置”保存服务地址、模型与图片开关；远程服务须使用 HTTPS，本机回环地址可使用 HTTP。点击“检测连接”只请求所示服务的模型列表，不读取窗口；列表可达不代表图片识别可用。密钥仍通过运行时环境配置，设置窗口不接收或保存密钥。“功能”页可关闭或重新启用随包插件，不提供插件下载或安装。

“检测图片识别”会主动发送一张鲸汐生成的数字图片，可能消耗一次模型额度；不读取你的窗口，不自动重试。读图检测成功只确认本次基础图片传输和识读，不代表所有软件都能正确解释或定位。服务恢复后可以直接发起新提问，无需因一次连接失败重启鲸汐。

主分支可构建自包含的 Windows x64 安装包。安装页展示软件许可协议、隐私说明和当前连接配置。点击一次“同意协议并安装”后，即可拖鲸鱼求助。启动时不会自动读取窗口，也不会再次要求确认。设置隐私页可查看协议或撤回同意。撤回、接收方或模型变化、发送范围或条款变化、同意记录不可用时，须重新运行安装程序确认。

拖入目标窗口后，按问题填写目标；需要时点击“选择识别区域”并框选。阅读解释或指路后自行操作目标软件，或结束会话。接收方、模型、发送范围或条款改变时重新确认。

在结果页可以直接输入并提交下一问。如果想先自行操作，请点“继续提问”。点选后到提交前，鲸汐暂停读取窗口内容。切窗时已发送的识别继续处理，结果在返回原窗口并通过核对后显示。关闭对话条或拖走鲸鱼可结束绑定，目标关闭或撤回同意也会结束。新增发送范围或授权说明变化时，旧授权不会自动沿用。

### 从源码运行

需要 Windows 与 .NET 8 SDK，在项目根目录执行：

```powershell
dotnet build src/CetaFae.Checks/CetaFae.Checks.csproj -c Debug
dotnet run --project src/CetaFae.Checks -c Debug --no-build
dotnet run --project src/CetaFae.Probe -c Release -- --guide
```

前两条构建并运行无桌面检查；最后一条打开鲸汐。使用 `--base-url https://your-service.example/v1 --model your-model` 覆盖本次启动的连接，在设置中明确保存后才持久化。可选鉴权仅从进程环境变量 `CETAFAE_API_KEY` 读取，不要提交密钥。非敏感设置存于当前用户的 `%LOCALAPPDATA%/CetaFae/settings.json`；配置损坏时停止识别，核对并保存后重新运行安装程序确认。

### 构建安装候选

在 Windows 安装 Inno Setup 6.7.4（含简体中文语言文件）和 .NET 8 SDK，然后运行：

```powershell
./installer/Build-Installer.ps1 -Compiler 'C:/Program Files (x86)/Inno Setup 6/ISCC.exe' -ChineseMessagesFile 'C:/Program Files (x86)/Inno Setup 6/Languages/ChineseSimplified.isl'
```

输出位于 `.artifacts/installer/`。安装包内置 .NET 8 Windows 桌面运行时，无需预装 .NET，可离线安装。点击「同意协议并安装」后，安装器会先关闭当前会话中即将被覆盖的鲸汐，再安装并启动新版。默认安装到当前用户目录，提供开始菜单入口和卸载支持，无需管理员权限。安装协议显示现有非敏感配置；取消或失败不新增同意，静默安装不可代替点击确认。模型服务仍需另行准备。解压或源码启动不会自动获得安装同意。

## 技术实现

- **Windows / C# / WPF / .NET 8**：原生窗口管理；优先使用 PrintWindow，画面不可用时尝试系统窗口捕获，两者均绑定所选窗口。后备通道可能显示 Windows 的捕获边框。
- **底座与插件分离**：底座负责授权、通用采集、模型传输、校验和生命周期；声明式插件负责软件匹配、遍历策略和任务规则。
- **截图为主、控件为辅**：初次说明依据本次画面，不依赖完整控件树；控件辅助精确定位，缺失时不妨碍图片解释。本机软件身份与画面判断分别呈现。
- **独立文字位置证据**：使用 Windows 本机文字识别，不额外安装识读引擎；文字坐标转换、候选去重、范围限制和显示前复核均在本机完成。它补充位置提示，不证明相邻控件可点击。
- **受约束的模型结果**：结构化返回、候选与范围校验、显示前复核；目标失效或请求取消后不恢复旧结果。
- **后台采集隔离**：短命辅助进程承载原生读取，可在取消或超时后回收，辅助进程也计入资源验收。
- **独立视觉反馈**：输入条和窗口边缘覆盖不向目标软件注入代码。

| 目录 | 用途 |
|---|---|
| `src/CetaFae.Probe` | Windows 宿主、交互、授权和采集 |
| `src/CetaFae.Plugins` | 与 UI 无关的插件数据契约和校验 |
| `plugins` | 声明式功能包与启用目录 |
| `src/CetaFae.Checks` | 可执行检查与生成数据夹具 |

## 开发计划

- 完成文字区域指路、绑定切换、设置恢复和输入的集中原生验收；覆盖单屏125%/150%/200%缩放，再验证混合缩放多屏。
- 完善通用理解、翻译及可见错误说明的准确性和异常恢复。
- 完成有界任务覆盖及主动连续指导的真实软件验收，每一步仍由用户操作。
- 完成集中隐私、平台、性能和真实任务验收；3000ms处理目标和90MB待命内存门槛仍未通过完整正式验收。
- 稳定契约并验证独立贡献流程，再提供公开第三方插件接口和安装能力。
- 满足明确任务、用户确认、快照和还原门禁后，另行推进受限文档编辑；当前未提供。

主要实测环境为简体中文 Windows 11、单显示器、100%缩放。受保护窗口、权限受限界面、异常控件提供程序和动态自绘画面可能无法处理；多屏、高 DPI 和广泛软件兼容性仍需集中验证。
