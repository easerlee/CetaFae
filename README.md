# 鲸汐 CetaFae

把小鲸鱼拖到一个窗口，了解它是什么、当前显示什么，并找到下一步该操作的位置。

简体中文 | [English](README.en.md)

> Windows 桌面开发预览。当前提供解释和指路，由用户操作目标软件；尚未通过正式发布验收。

## 功能亮点

- **轻量管理**：鲸鱼左键不弹出管理窗口；托盘和鲸鱼右键共用菜单。首次亲自同意后保存当前配置的授权与开关，后续启动恢复；配置或条款改变时重新确认，启动本身不采集或发送。
- **拖入即选窗**：小鲸鱼附着目标窗口显示对话条，按需呈现说明和指路标记；结束会话后恢复鲸鱼入口。
- **贴近目标的反馈**：说明从对话条下方展开，可靠定位时在控件旁显示短气泡；详情回到顶部统一阅读。收起保留会话与标记，×或清除标记结束会话，长文可滚动阅读。
- **认识当前窗口**：结合可见画面和本机软件身份，区分所属软件、界面用途与未知信息。通用视觉可尝试未适配的软件，不保证所有窗口都能识别。
- **解释与指路**：说明当前状态，目标不明确时询问一次。可靠定位后才标出控件，无法确认时明确说明，不猜点击位置。
- **局部画面分析**：优先使用可靠任务范围，也可手动框选需要分析的区域，无需逐个软件适配才能使用通用图片理解。
- **可选软件资料核对**：经单次确认后用产品名查询公共百科并显示来源；不认证本机程序真伪。
- **插件化能力**：通用视觉、软件身份和软件适配采用同一声明式契约，第一方功能也通过插件提供。

已有人工验证的代表流程包括 Edge 下载开关定位、Windows 更新暂停状态解释、WinRAR 解压目标路径指路，以及记事本生成文字的区域解释。这不代表相关软件全部功能已覆盖，也不代表最新源码的所有路径已完成回归。

## 安全保障

- **明确授权与随时关闭**：启用前说明发送范围、接收地址、模型与留存情况。关闭后停止新采集和请求，使进行中的会话失效；已发送内容无法从上游撤回。
- **只处理所选窗口**：不先截图整个桌面再裁剪，不自动读取其他窗口或后台标签页。
- **限制外发范围**：初次了解窗口时可能发送所选整窗画面；明确目标后使用可靠局部范围或用户选区，范围不明则等待选择，不自动扩大到整窗。PrintWindow 仍会在本机内存绘制所选整窗后裁剪。
- **保守拒绝敏感内容**：发现可见密码字段或可识别凭据文字时停止，隐私检查不可用时拒绝继续；这不是通用秘密识别或像素脱敏保证。
- **不保存会话原文**：客户端不持久保存图片、控件原文和问答；固定元数据日志保留7天，清理失败可能延迟。代理及上游模型的留存政策尚未核实。
- **用户掌握操作权**：当前不自动点击、输入目标软件、修改设置、执行解压或写入文档。切窗、关闭目标、撤权和结束会话会清理失效结果。

## 快速开始

从 [GitHub Releases](https://github.com/easerlee/CetaFae/releases) 下载 Windows x64 预览包，解压后运行 `CetaFae.Probe.exe`。需要 Windows 和 [.NET 8 桌面运行时](https://dotnet.microsoft.com/download/dotnet/8.0)。发布附件可能落后于主分支，以对应版本说明为准。

默认服务为 `http://127.0.0.1:8787/v1`，模型为 `deepseek-v4.1-flash`。请先准备兼容模型服务；鲸汐不附带模型或代理。图片理解需要服务支持多模态输入。

首次拖入会在尚未授权时显示说明，也可从鲸鱼右键或托盘打开“查看云端授权”。请阅读并亲自确认，再重新拖入目标窗口，按问题填写目标；需要时点击“选择识别区域”并框选。阅读解释或指路后自行操作目标软件，或结束会话。

### 从源码运行

需要 Windows 与 .NET 8 SDK，在项目根目录执行：

```powershell
dotnet build src/CetaFae.Checks/CetaFae.Checks.csproj -c Debug
dotnet run --project src/CetaFae.Checks -c Debug --no-build
dotnet run --project src/CetaFae.Probe -c Release -- --guide
```

前两条构建并运行无桌面检查；最后一条打开鲸汐。使用 `--base-url https://your-service.example/v1 --model your-model` 指定服务。可选鉴权仅从进程环境变量 `CETAFAE_API_KEY` 读取，不要提交密钥。

## 技术实现

- **Windows / C# / WPF / .NET 8**：原生窗口管理、UI Automation 控件读取与所选窗口捕获。
- **底座与插件分离**：底座负责授权、通用采集、模型传输、校验和生命周期；声明式插件负责软件匹配、遍历策略和任务规则。
- **双路理解**：控件语义辅助可靠定位，图片分析覆盖未适配界面；本机进程/产品身份与模型的画面判断分别展示。
- **受约束的模型结果**：结构化返回、候选与范围校验、显示前复核；目标失效或请求取消后不恢复旧结果。
- **后台采集隔离**：短命辅助进程承载原生读取，可在取消或超时后回收，辅助进程也计入资源验收。
- **独立视觉反馈**：输入条和窗口边缘覆盖不向目标软件注入代码。

| 目录 | 用途 |
|---|---|
| `src/CetaFae.Probe` | Windows 宿主、交互、授权和采集 |
| `src/CetaFae.Plugins` | 与 UI 无关的插件数据契约和校验 |
| `plugins` | 声明式功能包与启用目录 |
| `src/CetaFae.Checks` | 可执行检查与生成数据夹具 |

## 开发计划

- 完成授权恢复、托盘菜单及轻量交互的原生兼容性验收。
- 提升通用窗口理解、范围选择和异常恢复的可靠性。
- 完成集中隐私、平台、性能和真实任务验收；3000ms处理目标和90MB待命内存门槛仍未通过完整正式验收。
- 完成精修鲸鱼、水体和动效的原生视觉验收。
- 稳定契约并验证独立贡献流程，再提供公开第三方插件接口和安装能力。
- 满足明确任务、用户确认、快照和还原门禁后，另行推进受限文档编辑；当前未提供。

主要实测环境为简体中文 Windows 11、单显示器、100%缩放。受保护窗口、权限受限界面、异常控件提供程序和动态自绘画面可能无法处理；多屏、高 DPI 和广泛软件兼容性仍需集中验证。
